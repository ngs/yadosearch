Useful for traveling, when you have missed the last train.

This application uses the following APIs.
 * Jalan Web Service's "Yado Search API".
 * Rakuten Webservice's "Travel API".

You can search hotels in the following way
 * By hotel name
 * By railway ( Area>Line>Station )
 * By current location
 * By landmarks (Area>Prefecture>LargeArea>Landmarks)
 * By area ( Area>Prefecture>LargeArea>SmallArea )

You can reserve hotels using your iPhone / iPad.
Also the following web services are supported, for rechecking on your Mac / PC.
 * Delicious
 * Evernote
 * Facebook
 * Twitter
 * Instapaper
 * Tumblr
 * Twitter

etc...
